# Datasheet AstraPIO

DS APIO 001, révision documentaire 1.1, 23 septembre 2026. Interface ABI 5.

- [Datasheet et manuel de référence — PDF](AstraPIO_Datasheet_ABI5_Rev1.1_FR.pdf)
- [Version Word modifiable](AstraPIO_Datasheet_ABI5_Rev1.1_FR.docx)
- [Lecture en ligne](../reference.md)

Brochage logique, horloge et reset, interface SPI, cartes de registres,
jeu d’instructions, moteur temporel, pilote C et gestion des erreurs.
Le document s’adresse à l’utilisateur du circuit et au concepteur de son
interface matérielle ou logicielle.

Le [démarrage rapide](../getting-started.md) fournit un premier programme.
Le cas du remplacement en direct d’un flux WS2812 fait l’objet de
[la note d’application AN APIO 001](../application-notes/AN-APIO-001-ws2812-live-patching.md).

Données préliminaires : le comportement logique est spécifié ; la
caractérisation électrique et la validation sur silicium restent à effectuer.
